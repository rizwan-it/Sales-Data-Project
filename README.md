Sales Data Project

📊 Project Overview

This project analyzes sales data using Microsoft Excel.

🛠️ Tools Used

- Microsoft Excel / WPS Spreadsheet
- Excel Formulas
- Basic Data Analysis

📁 Dataset

The dataset contains:

- Product names
- Quantity sold
- Product prices
- Total sales

🧮 Calculation

Total sales were calculated using the formula:

"Quantity × Price = Total"

📌 Project Purpose

The purpose of this project is to practice spreadsheet data analysis, formulas, and data organization.
